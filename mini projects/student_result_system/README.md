# Student Result System
A progressively improved Python mini-project demonstrating:

- Input validation using try/except
- Range checking (0-100)
- Error handling
- Multi-student support using list of dictionaries
- Clean code refactoring with reusable functions
- Search functionlity using unique Roll No.

----

## Versions

### v1 - Input Validation
Single student result system with try/except and range validation.

### v2 - Multi-Student Support
Extended system to handle multiple students using list of dictionaries.

### v3 - Refactored Structure
Seperated result calculation into a resuable function using tuple unpacking.

### v4 - Roll Number & Search
Introduced Roll Number as a unique identifier and implemented search funtionality using Flag-based loop control.
